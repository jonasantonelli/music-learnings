## Notas de estudo

A cifra segue a harmonia padrão do Real Book, como Miles Davis tocou em *Walkin'* (1954).

Solar é uma música de 12 compassos — mas não é um blues. É uma cadeia de ii–Vs que **tonicizam um novo tom a cada dois a quatro compassos**, cada um um tom inteiro abaixo do anterior: `C menor → F maior → Eb maior → Db maior → de volta a C menor`.

**Compassos 1–2 (CmMaj7):** Tônica menor com 7ª maior — use **C menor melódica**. O B natural é a nota de cor; deixe-o soar.

**Compassos 3–4 (Gm7 / C7):** ii–V para F. A tônica menor *vira* dominante: `Cm → C7` só eleva a 3ª (`Eb → E`). Use **G Dórico → C Mixolídio**, ou pense numa única escala (F maior) nos dois compassos.

**Compassos 5–6 (FMaj7):** Primeiro novo centro tonal. **F maior** (ou F Lídio).

**Compassos 7–8 (Fm7 / Bb7):** O mesmo truque dos compassos 3–4, um tom abaixo: a tônica fica menor (`A → Ab`) e vira o ii de Eb. **Eb maior** nos dois compassos.

**Compasso 9 (EbMaj7):** Segundo centro tonal, por apenas um compasso. **Eb maior**.

**Compasso 10 (Ebm7 Ab7):** Mais uma vez: Eb fica menor e vira o ii de Db. **Db maior** no compasso todo.

**Compasso 11 (DbMaj7):** Terceiro centro tonal — Db é o bII de C, então esta é também uma cor napolitana. **Db maior** ou Db Lídio.

**Compasso 12 (Dm7b5 G7(b9)):** ii–V menor de volta para C menor. **D Lócrio → G alterada** (ou C menor harmônica no compasso todo).

### Notas-guia

As 3ªs e 7ªs se movem por meio tom ao longo de toda a música — a cadeia `Bb → A → Ab → G → Gb → F` (7ªs de cada ii e 3ªs de cada V) é a espinha dorsal de qualquer solo.

### Estratégia de estudo

1. **Arpeje só os alvos maj7:** `CmMaj7 — FMaj7 — EbMaj7 — DbMaj7` para ouvir a descida por tons inteiros.
2. **Ouça o pivô maior → menor:** toque `FMaj7 → Fm7` e `EbMaj7 → Ebm7`, abaixando apenas a 3ª. Esse movimento de uma única nota é todo o truque da música.
3. **Toque em todos os tons:** com 12 compassos, é o exercício de ii–V mais eficiente do Real Book.
